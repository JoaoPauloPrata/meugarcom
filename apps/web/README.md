# @seugarcom/web

Front do Meu Garçom (Vite + React 19). Landing page e waitlist, persistindo direto no
Supabase via `src/lib/supabase.js`.

**Toda alteração aqui deve ser feita e validada com a skill `ui-ux-pro-max`** (ver
`CLAUDE.md` na raiz). Carregue a skill antes de editar e revise o resultado contra as
guidelines dela depois.

```sh
npm run dev      # a partir da raiz do monorepo
```

Variáveis de ambiente em `.env` (modelo em `.env.example`).
